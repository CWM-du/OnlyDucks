# Risk Register

| Risk | Severity | Mitigation | Owner |
|---|---|---|---|
| SSO unavailable or undocumented | Critical | Verify access and provider contract immediately | TL2 |
| Oscar API access/contract unclear | Critical | Test minimal request and confirm limits | TL3 |
| Content sources inaccessible | High | Confirm API/feed access and mappings | TL4 |
| Short delivery window | Critical | Freeze scope and integrate daily | Project Manager |
| Duplicate active sessions under concurrency | High | Enforce atomic database constraint/transaction strategy | TL1 |
| Conversion attribution unavailable | Medium | Separate outbound click measurement from downstream conversion | TL4 |
| Deployment configuration incomplete | High | Deploy early candidate and rehearse | TL1 |
