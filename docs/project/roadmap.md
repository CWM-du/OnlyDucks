# OnlyDucks MVP Roadmap

**Delivery target:** 2026-11-11  
**Planning note:** This is an accelerated recovery schedule, not the original 6–10 week estimate. It depends on immediate access to existing integrations and team availability.

| Date | Milestone | Exit criteria |
|---|---|---|
| 2026-11-02 | Foundations and audit | Repository, environment, and integration feasibility confirmed |
| 2026-11-03 to 2026-11-05 | Core implementation | Authentication, mentor, and content paths work against available integrations |
| 2026-11-06 to 2026-11-08 | Integrated candidate | End-to-end journey, analytics, and feature freeze |
| 2026-11-09 | QA checkpoint | Regression, security, and critical defects reviewed |
| 2026-11-10 | Release preparation | Deployment rehearsal, documentation, acceptance review |
| 2026-11-11 | Pilot delivery | Deploy, smoke test, demonstrate, and hand over |

## Critical dependencies
1. Shared identity integration.
2. Oscar API access and contract.
3. Content API/feed access.
4. Database and hosting availability.

## Scope control
P0 requirements are mandatory. P1/P2 items must not displace pilot acceptance criteria without project manager approval.
