# Incident Response

## Initial procedure
1. Record the incident, timestamp, environment, and user-visible impact.
2. Notify the project manager and the responsible team lead.
3. Protect user data and avoid sharing secrets in GitHub issues.
4. Identify whether the issue concerns authentication, Oscar API, content sources, database, or deployment.
5. Mitigate safely and preserve relevant non-sensitive logs.
6. Verify recovery with smoke tests.
7. Record root cause, remediation, and follow-up actions.

For security incidents, restrict access and rotate affected credentials through the relevant provider. Do not post credentials or personal data in incident records.
